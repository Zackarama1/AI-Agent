# QUARRY

A personal multi-asset market terminal for desktop and iPad: command line, function codes,
dockable panels, real-time and delayed data with clear provenance. Personal use only.

- **Status:** Phase 0 (foundations) done. See `docs/PLAN.md`.
- **Run it:** `cp .env.example .env && make up` → http://127.0.0.1:8000
- **iPad:** see `docs/DEPLOY.md` (Tailscale + Add to Home Screen).
- **Develop:** `make install`, `make dev`, `make test`, `make lint`. See `CLAUDE.md`.

Try `HELP`, `STAT`, `KEYS`, `VOD LN DES`, `AAPL US GP 1Y` in the command line.
