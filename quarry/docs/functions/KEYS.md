# KEYS — keyboard shortcuts and touch gestures

`KEYS` (or `?`) shows the keyboard cheat sheet and the iPad gestures. Keyboard:
Ctrl/⌘+K or `/` focus the command line · Enter / Shift+Enter run in the focused / a new panel ·
Tab complete · ↑/↓ history · Esc leave · F1 HELP · Ctrl+1–9 focus panel · Ctrl+L link colour ·
Ctrl+S save workspace. iPad: tap chips, tap a pane to focus, 1/2/3 pane buttons, swipe the top
bar to change workspace.
